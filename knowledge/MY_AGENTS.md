# My Agents — Registry

Not market research. A map of the owner's own agents and what is already known about each — built as a byproduct whenever one of them is investigated as an Intelligence Report target, and consulted whenever a new external finding needs to be checked for fit against the existing portfolio.

Distinct from `CAPABILITY_MAP.md`: that file is generic evidence about how AI agent systems work in general, gathered from third parties. This file is specifically the owner's own agents and their already-known mechanisms — the thing a new finding gets matched against.

Per agent:

- **Domain** — what it's responsible for.
- **Known mechanisms** — what this agent already does, in enough detail to judge whether a new finding strengthens, duplicates, or is irrelevant to it.
- **Investigated** — when it was last the subject of an Intelligence Report (or when its mechanisms were otherwise confirmed).
- **Source** — which report/artifact the mechanisms were drawn from.

Matching a new finding against this registry is a separate act from producing an Intelligence Report: the input is a finding (an article, a mechanism, a tool), not a target; the output is a short relevance read per agent, with a reason — not a ten-section report, and not a recommendation to act.

## AI Business Producer (proposed, not yet built)

**Domain**: working name only, owner-originated. Takes the owner's business from scratch (idea) or an existing business, brings it to a business breakdown/company structure, then coordinates a set of specialized AI agents by business function — not living specialists, an explicit v1 limitation the owner set. The business owner remains the one who makes key decisions, not the coordinating agent. Meant to be reusable across businesses, not built for one.

**Known mechanisms**: none of its own yet — this entry is the external evidence base a future design should be checked against, not a description of an existing mechanism (same status as the Engineering Agent entry before it was built). What the evidence base actually contains:
- A real category of production and near-production systems already exists doing close to this: Cofounder.co (funded, independently reported ~10,650 companies running on it), Vora IQ (small but independently corroborated real usage), GoodHelp (one specific, self-referential production case), and — narrowly scoped to software delivery rather than general business — MetaGPT/ChatDev (both established, paper-backed, tens of thousands of GitHub stars).
- Real, observed specialization pattern to check any future role list against: Marketing, Finance, Sales/GTM, Operations, Legal/Compliance, Product/Engineering, Support converge almost everywhere; HR/People, Strategy, standing Research, and Documentation/investor-relations recur less universally; literal legal *entity-formation/company-structure* work is the least-covered function found anywhere (only one pre-launch product, Aqen, names it explicitly).
- Real, observed review/decision-authority mechanisms to check any future design against: soft human-approval gates before risky actions (Cofounder.co), hard-coded numeric business-logic refusals tied to live data (Vora IQ's Ledger — refuses to endorse scaling below LTV:CAC 3:1 or under 6-month runway), and shared-context substrates that keep multiple specialists coherent (Vora IQ's Business Context Layer) — the last of these is conceptually the same problem this project's own `DECISIONS.md`/`OPEN_QUESTIONS.md` shared-file convention already solves.
- **Explicitly named infrastructure gap**: none of the real, working coordination-shape findings above require new infrastructure beyond what Engineer↔Researcher's already-proven single-shot background-agent-with-brief mechanism provides. What *would* require new infrastructure and was not found solved cheaply anywhere: live external business-tool integrations (Stripe/CRM/banking) and continuous/standing parallel execution across many specialist agents at once, as opposed to one agent invoked once per brief.

**Investigated**: 2026-08-17 — World Research step inside Engineer's `idea-calibration` gate (Confidence Low result triggered this search). Not a full Intelligence Report on a named existing product — a narrow-brief evidence search with a criterion fixed before search, per `OPEN_QUESTIONS.md`-practice. Design of this agent has not started; Responsibility Boundary Gate observed (Research only, no design/owner-decision content produced here).
